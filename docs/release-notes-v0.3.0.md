# Separador Vocal 0.3.0

Incluye todo lo publicado en 0.2.0 y suma:

- Botón **Exportar stems** para copiar los WAV actuales a una carpeta que elige el usuario.
- La exportación usa una tarea en segundo plano, crea una subcarpeta única y elimina resultados parciales si hay errores.

Continúan los mismos requisitos de Windows x64 y FFmpeg. La separación de batería, bajo y otros sigue pendiente de resolver las condiciones de los pesos de un modelo de cuatro stems. El instalador no está firmado digitalmente.
